## 0.1.0 (2026-09-17)

### Features

* **routing:** prefixed alias resolution and combo expansion with cycle detection and a depth cap
* **routing:** ordered failover — a tier that fails before emitting content moves to the next, transparently
* **routing:** configurable retry contract with exponential backoff and `Retry-After` support
* **routing:** `router.catalog_ttl_ms`, a cached routing catalog invalidated by every admin write
* **routing:** global and per-connection upstream concurrency caps with a bounded acquire timeout
* **routing:** per-connection connect and stream-idle timeouts
* **providers:** OpenAI-compatible wire format — `/v1/chat/completions` (SSE and JSON), `/v1/responses`, `/v1/models` and `/v1/models/info`
* **providers:** Anthropic-native wire format — `/v1/messages` and `/v1/messages/count_tokens`
* **providers:** streaming parity for tool calls, reasoning and usage across both wire formats
* **providers:** `command-code` upstream with automatic fallback to the CLI transport
* **providers:** CodeBuddy Intl (`codebuddy-intl`) stream adapter
* **providers:** 55 built-in provider presets across API-key, free-tier and local tiers
* **providers:** extra rotating API keys per connection, with fallthrough before the next tier
* **proxy:** thin proxying for embeddings, images, audio, video, moderations, search and SSRF-guarded web fetch
* **security:** upstream credentials encrypted at rest with AES-256-GCM and boot re-encryption of legacy rows
* **security:** router-issued API keys hashed with SHA-256, optionally stored reversibly for dashboard reveal
* **security:** zero-config dashboard auth — password sign-in with Argon2, rotating sessions, first-run setup code
* **security:** bearer-token enforcement on the admin API when bound beyond loopback
* **keys:** per-key rate limiting, daily/weekly/monthly/lifetime budgets and token limits with `off`/`warn`/`block` modes
* **keys:** reusable plans that bundle an allowlist, rate limit and budgets for any key
* **keys:** per-key model allowlists with exact and `prefix/*` wildcards, plus key and plan expiry
* **usage:** per-attempt metering with prompt, completion, cached and reasoning token breakdowns
* **usage:** usage filters, per-model rollups, hour/day trend buckets and a per-record detail sheet
* **usage:** model pricing overrides with optional LiteLLM/models.dev catalog sync and a reasoning-token premium
* **usage:** self-service usage and catalog at `/me` for client keys
* **token-saver:** deterministic pipeline — Slimmer/RTK, Headroom, terse/caveman and ponytail — that fails open
* **token-saver:** measured, priced savings rollups on Usage, Token Saving and Prometheus
* **token-saver:** playground with a Token Saver inspector and a streaming Chat tab
* **dashboard:** embedded dashboard with a model catalog, activity feed, API guide and backup/restore
* **dashboard:** settings editable at runtime and hot-applied from SQLite
* **dashboard:** Prometheus metrics plus a liveness/readiness probe split
* **ops:** system tray on Windows and macOS with graceful shutdown
* **ops:** CLI `install`, `uninstall` and `status` commands with auto-start
* **ops:** npm packages, `install.sh`/`install.ps1` installers, multi-stage Dockerfile and CI
