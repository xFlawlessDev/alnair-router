# @xflawlessdev/alnair-router-win32-x64

The prebuilt Windows x64 binary for
[`@xflawlessdev/alnair-router`](https://www.npmjs.com/package/@xflawlessdev/alnair-router).

Install that package instead. This one is pulled in automatically as an
optional dependency, and exists so each platform can ship its own binary
without a postinstall download.
